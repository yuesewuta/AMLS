## 2. 100 万 DOF 模型设计

### 2.1 几何与网格

| 参数 | 值 | 说明 |
|---|---|---|
| 几何 | 悬臂块 100 m × 100 m × 32 m | 单位 m（SI） |
| 单元 | C3D8 规则六面体，1m×1m×1m | 单种单元、节点规则编号 |
| 网格 | `nx=100, ny=100, nz=32` | 单元数 320,000 |
| 节点 | 336,633 | `(nx+1)(ny+1)(nz+1)` |
| 约束 | `*BOUNDARY` 固支 x=0 面（U1=U2=U3） | 消 6 刚体模态 |
| **自由 DOF** | **999,900 ≈ 100 万** | `3×(336633−3333)` |
| 材料 | 钢 E=210e9 Pa, ν=0.3, ρ=7800 kg/m³ | SI 一致 |

关键点：
- **K 对称正定**：线弹性无 preload/初始应力，Standard 特征求解只收对称矩阵；固支消刚体 → K 正定。
- **M 对称正定**：一致质量阵（默认 `MASS` 即 consistent），无集中质量技巧 → SPD。
- DOF 精确到个位 999900，可放心宣称"百万级"。

### 2.2 inp 生成

已有工具 `tools/gen_abaqus_cantilever.py` 完全适用，只需按新网格与新的两步矩阵导出改模板：

```bash
python tools/gen_abaqus_cantilever.py --nx 100 --ny 100 --nz 32 --nev 100 -o cant_1m.inp
```

## 3. 求解参考解（Abaqus AMS）

### 3.1 inp 步骤（2025 版语法）

```
*STEP, NAME=freq
*FREQUENCY, EIGENSOLVER=AMS, NUMEIGEN=100
*END STEP
```

- **AMS 是 SIM 架构 add-on**（文档确认 `Table 1. Software architectures`），比 Lanczos 快，尤其适合大 DOF 多模态。
- `NUMEIGEN=N` 控制求前 N 阶；`--nev` 对应 amls_solve 的请求个数。
- **AMS 限制（文档确认）**：
  - 不支持阻尼（本模型无阻尼，无视）
  - 不支持刚体模态（本模型已固支消去，OK）
  - 仅在 `.inp` 中可用（Abaqus/CAE 不支持 AMS，但我们是文本 inp，OK）
  - 不支持 composite modal damping 等（无关）
- 若 AMS 出问题，用 Lanczos 兜底（`EIGENSOLVER=LANCZOS`）——同模型同矩阵，参考解一致。

### 3.2 运行

```bash
cd bench_abaqus
abaqus job=cant_1m cpus=8
```

性能统计（Windows）：
- 峰值工作集：任务管理器 → cant_1m 进程最大内存（或 `Get-Process` 轮询）
- 耗时：job 起止（`.log` 里 `Begin Analysis / End Analysis` 时间戳）
- 输出：`.dat` 的 `EIGENVALUE OUTPUT` 表（模号、频率、圆频率、周期、广义质量）

### 3.3 疲劳点确认（记忆中已知）

`mp_mpirun_path` 需配置 MPI 才能 `cpus>1`；本机无 Microsoft MPI，系统装完 MS-MPI 后 `mpi_config.env` 会自动探测到 `Program Files\Microsoft MPI\bin\mpiexec.exe`。单核 `cpus=1` 可绕开，但 1e6 DOF AMS 请多核。

## 4. 矩阵导出（K/M 提取）

### 4.1 2025 版两步流程（与旧版不同）

**旧版惯用**：`*MATRIX GENERATE, STIFFNESS, GLOBAL, FORMAT=COORDS` 一步导出文本。
**2025 版（文档确认）**：
1. `*MATRIX GENERATE, STIFFNESS/MASS` —— 把矩阵写入**二进制 `.sim` 文件**（Global 默认）
2. `*MATRIX OUTPUT, STIFFNESS, FORMAT=COORDINATE` —— 从 `.sim` 拷贝为**文本 `.mtx` 文件**

### 4.2 inp 写法

```
*STEP, NAME=matgen, PERTURBATION
*MATRIX GENERATE, STIFFNESS, GLOBAL
*MATRIX GENERATE, MASS, GLOBAL
*MATRIX OUTPUT, STIFFNESS, FORMAT=COORDINATE
*MATRIX OUTPUT, MASS, FORMAT=COORDINATE
*END STEP
```

> 注意：`GLOBAL` 下 `*MATRIX OUTPUT` 输出的是标准 `COORDINATE` 文本。若需单元级 / DMIG 用其他 FORMAT。

### 4.3 COORDINATE 格式（文档确认）

- 每个矩阵条目一行，**逗号分隔三元组：`行号, 列号, 值`**
- 行号/列号 = **方程号**（不是节点号；Abaqus 内部把 DOF 映射成方程号）
- 文件名：`jobname_STIF3.mtx`（刚度）/ `jobname_MASS3.mtx`（质量）—— 后缀 `_STIF`/`_MASS` + 矩阵在 step 中的编号 `3`
- 对称矩阵是否只输出单三角：文档未明说；需小模型实测确认（见 §7）

### 4.4 体积估算（1e6 DOF）

| 矩阵 | 非零估算 | 文本体积 | 说明 |
|---|---|---|---|
| K（上三角） | ~1300 万 | ~590–700 MB | 每节点 ~26 邻接 × dof/2 |
| K（全阵） | ~2600 万 | ~1.2 GB | 若 Abaqus 输出全阵 |
| M（一致） | ~900 万 | ~270–400 MB | 对角占优 |
| inp | — | ~27 MB | 336633 节点 + 32 万单元 |

磁盘空间需预留 **≥2 GB**（含 .sim、.mtx、.odb、临时文件）。

### 4.5 转换喂 `amls_solve`

`amls_solve --K K.mtx --M M.mtx` 读取 Matrix Market `coordinate + symmetric` 格式。
写一个小转换脚本：
1. 解析 Abaqus `.mtx` 逗号分隔 triplet → 坐标换为空格分隔
2. 加 Matrix Market banner：`%%MatrixMarket matrix coordinate real symmetric` + `%` 注释行 + `N N NNZ`
3. `amls_solve` 的 symmetric 标志会展开为全矩阵（源码 `matrix_market.hpp` L9 注释确认）

> 兼容性验证点：M 是否被 Abaqus 输出为对称且只含上三角/下三角；若 Abaqus 输出全对称两半，需去重。

## 5. 完整执行协议（装好 Solver 后）

### 5.1 单次运行的理想 inp（一个 job 完成全部）

```
*HEADING
... 节点/单元/材料/边界 ...
*STEP, NAME=freq
*FREQUENCY, EIGENSOLVER=AMS, NUMEIGEN=100
*END STEP
*STEP, NAME=matgen, PERTURBATION
*MATRIX GENERATE, STIFFNESS, GLOBAL
*MATRIX GENERATE, MASS, GLOBAL
*MATRIX OUTPUT, STIFFNESS, FORMAT=COORDINATE
*MATRIX OUTPUT, MASS, FORMAT=COORDINATE
*END STEP
```

一个 job 顺序执行：先频率提取（参考解），再矩阵生成+输出（K/M）。省一次装配。

### 5.2 性能/内存记录项

| 项 | 来源 |
|---|---|
| 参考频率 N 阶 | `.dat` EIGENVALUE OUTPUT |
| 总求解耗时 | `.log` / 计时 |
| 峰值内存 GB | Windows 性能监视（进程 cant_1m* 峰值工作集） |
| 每阶段耗时 | `.msg`/`.dat` 阶段标记；或分步 job 分别计时 |
| 输出矩阵 | `cant_1m_STIF3.mtx` / `cant_1m_MASS3.mtx` |

### 5.3 与 AMLS 对比口径

- 同机器（本机）、同模态数（NUMEIGEN = `--nev`）
- 同一 K/M（Abaqus 导出的矩阵直接喂 amls_solve）
- 记录 3 个对比量：频率参考解一致、总耗时、峰值内存
- Amls_solve 已内建分段壁钟/CPU 计时 + 峰值工作集输出（见记忆）

## 6. 风险与待验证点

1. **Solver 未装**（最大阻塞）——必须先重装完整卷，`verify` 过 Standard/AMS。
2. **对称矩阵输出形态**（单三角 vs 全阵）——小模型实测。
3. **方程号 ↔ 原 DOF 映射**——`COORDINATE` 用的是方程号；若需映射回节点/DOF 需 `*MATRIX OUTPUT, FORMAT=LABELS` 另导一份标签。
4. **体积**：1.6GB 文本导出可接受，但确保磁盘 ≥2GB。
5. **MPI**：多核需 MS-MPI；否则 `cpus=1` 先跑小模型验证链路。
6. **AMS SIM 架构**：SIM 架构不支持某种 solver 配置的已知项要留意（文档提到 SIM 不支持部分功能，本模型无阻尼无刚体，不受影响）。
