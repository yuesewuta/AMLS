# Abaqus 10万 DOF 悬臂梁 AMS 消去树（cant_31, 98,304 DOF）

## 1. 数据来源与重建方法

- 算子：`ABA_PAMS_EXPORT_SOLVER_DATA` 探针导出的 `cant_31_stf`（AMS 超节点行序刚度算子，已含多级缩聚后的跨级耦合），nrow=98,304，nnz=3,688,476（不含对角，行内列号升序，第 r 行首列 ≥ r+1）。
- 超节点块识别：块内行度逐行 −1（`nnzp[i]==nnzp[i-1]-1`），行度跳变处即块边界（与 cant_20 重建同法）。
- 父子关系：块 i 行内出现的大于块末列的最小列号所在块为 parent(i)（消去树标准规则）；行内全部更高列号所在块构成祖先耦合集，含**跨级直连**（不经过父块）。
