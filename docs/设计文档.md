# AMLS 求解器设计文档（纯代数版）

> 版本：v0.2（2026-10-04）——按用户要求**完全剥离工程语义**，系统内部只使用代数概念与树结构概念
> 依据文献：Gao et al. 2008（ACM TOMS，实现主蓝本，其本身即纯代数表述）、Bennighof & Lehoucq 2004

---

## 0. 术语约定（本设计的语言边界）

系统代码、接口、文档内部**只允许**出现下列代数概念；工程词汇仅允许出现在文献综述性质的背景说明中。

| 禁止在系统设计中使用（工程术语） | 系统内使用的代数术语 |
|---|---|
| 刚度矩阵 / 质量矩阵 | 矩阵 K / 矩阵 M（仅性质：K 对称、M 对称正定） |
| 子结构 / 超单元 | **叶节点**（leaf node） |
| 界面 / 分离子 | **分割节点**（separator node） |
| 顶层界面 | **根节点**（root node，即无父的分割节点） |
| 子结构模态 / 约束模态 / 耦合模态 | 局部特征向量 / 谱分量 |
| 截止频率（cutoff frequency） | 截断阈值 λ_cut（纯谱参数） |
| 频率、振型、频率响应 | （不在系统范围内）特征值、特征向量 |
| Craig–Bampton 形式 | 块对角同余形式 |
| 模态综合（CMS） | 单层（ℓ=1）代数子结构 |
| 自由度（DOF） | 索引 / 未知数下标 |

**树模型是系统的唯一组织概念**：每个节点恰为三种角色之一——

```
enum class NodeRole { Leaf,       // 不再二分的索引集合
                      Separator,  // 分割节点：其索引集合把子图分成不连通的两部分
                      Root };     // 根节点：无父的分割节点（第一级分割）
```

节点间只有两种关系：`parent/children`（树结构）与 `ancestors/descendants`（派生查询）。任何关于"物理连接""单元""载荷"的概念都不得进入接口。

## 1. 问题定义与范围

求解对称广义特征值问题的低端部分谱：

```
K x = λ M x，  K ∈ Rⁿˣⁿ 对称，  M ∈ Rⁿˣⁿ 对称正定，  二者稀疏
```

| 项目 | 界定 |
|---|---|
| 矩阵性质 | 纯代数假设：K 实对称（半）正定、M 实对称正定；无任何物理语义要求 |
| 求解目标 | 最小 nev 个特征对 (θⱼ, zⱼ)，j = 1..nev |
| 精度标准 | 特征值相对误差 ≤ 4%（与用户既定标准"频率误差 ≤ 2%"严格等价：ε_f ≈ ε_λ/2） |
| 输入形态 | 稀疏矩阵对（MatrixMarket 文件 / 算例生成器），与来源无关 |
| 平台 | Windows / MSYS2 mingw64，单机串行优先；C++17 + CMake + Ninja + Catch2 |

## 2. 算法概述（代数表述）

输入矩阵对 (K, M)。对 |K|+|M| 的邻接图做递归二分（nested dissection），产生一棵树与重排序；树把行列索引集递归地划分为叶节点索引集与各层分割节点索引集。之后：

```
(1) 划分与重排：得 separator tree 与排列 P，使 (K, M) 呈嵌套块结构；
(2) 块分解：K = L D Lᵀ（块高斯消元；D 块对角，仅分割节点对角块被 Schur 更新）；
(3) 同余变换：L⁻¹(·)L⁻ᵀ 作用于 (K, M) → (K̂, M̂)；K̂ = D 块对角；
(4) 局部谱问题：每个节点 i 解 (K̂ᵢᵢ, M̂ᵢᵢ) 的局部广义特征问题
    （叶节点 K̂ᵢᵢ = Kᵢᵢ 原样；分割节点为更新后的稠密小块），
    按截断策略保留 kᵢ 个谱分量，组装 S = diag(S₁,…,S_N)；
(5) 投影：K̃ = SᵀK̂S（严格对角），M̃ = SᵀM̂S（块稀疏）；
(6) 投影问题求解：(K̃, M̃) 的低端特征对 → 回代 z = L⁻ᵀ S q；
(7) 反排列 P⁻¹ 恢复原索引序。
```

实现按两阶段组织（Gao et al. §3）：

- **Phase 1（消元-变换-投影交错）**：按树的 postOrder（叶→根）单趟遍历；每个节点完成"局部分解 → 局部谱问题（取部分谱）→ 用 Zᵢ 对祖先方向块右投影 / 对后代方向块左投影"。交错组织使 M̂ 永不显式存在。
- **Phase 2（Ritz 对计算）**：K̃ 对角、M̃ 块稀疏；n_proj ≤ 5000 时稠密 DSYGVD 全解，更大时走预留的移位反演接口。
- **L 的半隐式表示**（v1.1）：叶节点的 Lⱼᵢ = KⱼᵢKᵢᵢ⁻¹ 不显式存储，需要时经因子重算。

**结构性质与防爆炸约束**全部见《子块结构性质与加速机会分析》（P1–P14），其中 P3（K̃ 对角）、P5（Z-优先结合顺序）、P2（耦合块列稀疏 = 边界列）为架构硬约束。


设计原则：

1. 三类底层能力（图划分、稠密特征求解、稀疏直接解）全部抽象为**接口**，AMLS 核心只依赖接口与树模型；
2. 数值类型走模板 Traits：`template<typename Scalar, typename Index>`，v1 实例化 `<double, int64_t>`（与 METIS 的 `idx_t=int64` 对齐）；
3. 运行期多态用于"每问题一次"的组件选择；编译期模板用于热路径类型；
4. 每模块独立目录、独立 CMake target、独立 Catch2 测试；
5. **接口签名层面杜绝稠密化爆炸**：不存在显式求逆 API；局部谱求解签名只接受"区间/前 k 阶"请求（详见结构性质分析 §4 四条硬约束）。

## 4. 模块设计

### 4.1 core —— 基础类型

```cpp
// core/types.h
template<typename S, typename I> struct Traits {
    using Scalar = S;  using Index = I;
    using SparseMatrix = Eigen::SparseMatrix<S, Eigen::ColMajor, I>;
    using DenseMatrix  = Eigen::Matrix<S, Eigen::Dynamic, Eigen::Dynamic>;
    using Vector       = Eigen::Matrix<S, Eigen::Dynamic, 1>;
    using Permutation  = std::vector<I>;      // perm[new] = old
};
using DefaultTraits = Traits<double, int64_t>;

// core/pencil.h —— 矩阵对 (K, M)，纯数据，无语义
template<typename T> struct Pencil { SparseMatrix K, M; };
```

- `BlockView`：给定索引集合抽取/写回子块；
- 只存下三角，接口层统一对称语义。

### 4.2 io —— 数据进出

- `MatrixMarketReader/Writer`：`.mtx` 读写，symmetric 标志展开；
- `CaseGenerator`（谱已知的代数百科算例，与任何物理来源无关）：
  - `path_graph(n)`：链式图 Laplacian（三对角），λ_j = 2−2cos(jπ/n) 闭式谱；M = I 及三对角一致变体；
  - `grid_graph_2d(nx, ny)`：二维规则网格 Laplacian（5 点 stencil），λ_jk 闭式谱。

### 4.3 partition —— 图划分

```cpp
template<typename T>
class IPartitioner {
public:
    struct Result { SeparatorTree tree;  typename T::Permutation perm; };
    virtual Result recursiveBisection(const typename T::SparseMatrix& A,
                                      int nLevels) = 0;   // A = |K|+|M| 的邻接结构
    virtual ~IPartitioner() = default;
};
```

- `MetisPartitioner`：递归调用 `METIS_PartGraphRecursive` 自顶向下建树；终止条件：子图规模 ≤ `leafSize`（默认 ~500）或达到 `nLevels`；
- 分割节点的索引集 = 使两个子图不连通的顶点 separator——树模型中"分割节点"一词的唯一定义。

### 4.4 amls —— 核心

```cpp
// amls/separator_tree.h
enum class NodeRole { Leaf, Separator, Root };

struct TreeNode {
    Index id;
    NodeRole role;                 // 三角色之一
    std::vector<Index> indices;    // 本节点持有的行列索引（重排序后连续）
    std::vector<Index> children;   // 分割节点恰有 2 子；叶节点为空
    Index parent;                  // 根节点为 -1
    // 运行期缓存：局部谱 (Λᵢ, Zᵢ)、局部因子句柄
};
class SeparatorTree {
public:
    const TreeNode& node(Index id) const;
    std::vector<Index> postOrder() const;        // 叶→根遍历
    std::vector<Index> ancestors(Index id) const;
    std::vector<Index> descendants(Index id) const;
};
```


### 4.5 linalg —— 求解器接口层

```cpp
// 稠密广义特征求解（局部小问题 + 投影问题）
template<typename T>
class IDenseEigensolver {
public:
    virtual void solveAll(DenseMatrix& K, DenseMatrix& M,
                          Vector& w, DenseMatrix& V) = 0;       // dsygv/dsygvd
    virtual void solveInterval(DenseMatrix& K, DenseMatrix& M,
                               Scalar lo, Scalar hi,
                               Vector& w, DenseMatrix& V) = 0;  // dsygvx

// 稀疏对称直接解（块消元算子 + 移位反演支撑）
template<typename T>
class ISparseDirectSolver {
public:
    virtual void factorize(const SparseMatrix& A) = 0;          // Cholesky/LDLᵀ
    virtual void solveWithFactor(const DenseMatrix& B,

};

// 大规模局部谱问题 / 参考解（预留）

class IShiftInvertEigensolver { /* σ 移位下最小 nev 个特征对 */ };
```

### 4.6 reference / verify —— 验证支撑（同样无语义）

- `ReferenceSolver`：n ≤ 5000 用 LAPACK 全谱作金标准；更大用 Spectra `SymGEigsShiftSolver` 取低端；
- `ErrorMetrics`：特征值相对误差 |θ−λ_ref|/|λ_ref|（主指标，≤4%）；残差 r = ‖Kz−θMz‖₂/(‖Kz‖₂+|θ|‖Mz‖₂)；特征向量在 M-内积下的夹角。

## 5. 实现要点与风险（继承并引用预研结论）

《子块结构性质与加速机会分析》P1–P14 为本设计的性能前提；其中落实为代码硬约束的四条：

1. 块算子化（无显式逆）——P2/P5/P11；
2. 耦合块只存边界列（`colMap + denseCols`）——P2/P14；
3. 局部谱求解只支持区间/前 k 阶签名——P9；
4. K̃ 对角存储、M̃ 树块表存储——P3/P4/P8。

其余风险（SPD 保持与负主元断言 P10、L 半隐式 P11、n_proj 切换阈值 P12、截断阈值 η 扫描 P9）同前版，不再赘述。
