# 三项优化的运行与验证

当前程序支持单次 METIS_NodeND 分区、祖先对更新批处理以及 DAG 空闲容量驱动的内部并行。性能结果见本目录的实测报告；原始输入和参考解保持不变。

## 构建与测试

在本机 MinGW64 工具链环境下：

```bash
export PATH="/d/msys2/mingw64/bin:$PATH"
cmake --build build -j8
ctest --test-dir build --output-on-failure
```

MinGW 默认将静态 NETLIB LAPACK 的 BLAS 调用连接到 OpenBLAS，并包装六种 BLAS3 算子，使已经开始的 N7 局部谱任务能在其它 DAG 任务完成后获取内部线程预算。`-DAMLS_STATIC_LAPACK=OFF` 可构建旧 DLL 链接方式作对照。其它平台不启用 GNU ld 包装器。

## 选择分区方式

```bash
build/amls_solve.exe --K benchmark/matrices/boneS10/boneS10.mtx \
  --mass-scale 1 --fuser 0.2 --eta 4 --threads 16 \
  --partition nd --leaf-size 223 --quiet
```

`--partition bisect` 为递归二分，是当前默认值；`--partition nd` 只调用一次 METIS_NodeND，随后由消去树构造多叉分割树。ND 的 `leaf-size` 是合并阈值，不能保证叶块不超过该值；`nlevels` 不控制 ND 深度。两种树可产生不同的降阶维数、计算量和截断误差，不能将全部求解差异归为 METIS 调用次数的收益。

## 同树开关对照

环境变量存在即生效，关闭时应删除变量，而不是设置成 `0`。

| 环境变量 | 作用 |
|---|---|
| `AMLS_BATCH_OFF` | 恢复逐祖先对算术和逐对 DAG 任务，用于同树批处理对照 |
| `AMLS_NO_ADAPT` | 禁止 DAG 内部算子自适应并行，worker 数量仍由 `threads` 指定 |
| `AMLS_N7_SERIAL` | 禁止 N7 外层预算及 LAPACK BLAS3 包装器预算；其它自适应算子仍运行 |
| `AMLS_NO_MT` | 禁止 BLAS 和手工列分块的统一线程容量预留 |
| `AMLS_DEBUG_ADAPT` | 输出最高观测容量、预算申请/成功/竞争计数及部分 N7 耗时 |
| `AMLS_PROGRESS` | 输出求解内部阶段的开始标记 |

当 ready 队列为空且正在运行的任务不超过两个时，算子重新查询可用容量，最多申请八线程。BLAS 内部并行与手工列分块共用同一预算互斥；取得预算时在 DAG 锁内登记辅助线程，worker 出队遵守“运行任务数 + 借用辅助线程数 ≤ worker 数量”，算子结束后归还并唤醒队列。预算持有者不能等待尚未执行的 DAG 任务，只能等待自身辅助线程。最高观测档位与预算成功计数是不同指标；仅出现档位 3 不能证明 N7 获得并行预算。

祖先批处理将 u/Mtemp 的物理存储列拼接，再分组计算和散布。积矩阵的名义分块预算为 384 MiB；整块联板不受该预算限制，单个祖先组也可能超过预算。

## 保留可复核的计时

```bash
python tools/measure_optimizations.py \
  --commands-file benchmark/results/optimization_check/final_commands.json \
  --out-dir benchmark/results/optimization_check/new_comparison
```

输出目录必须不存在。脚本顺序运行，记录原始 stdout/stderr、真正的进程退出码、命令、环境开关、可执行文件 SHA256 和 Windows CPU/工作集采样。不要在计时期间并行运行编译、测试或其它数值任务。

应用阶段日志中的 CPU 秒是进程所有线程累计的 CPU 时间。在本机 16 个逻辑处理器上，`100 × CPU秒 / wall秒 / 16` 近似对应任务管理器总 CPU 百分比。单线程充分运行约为 6.25%。

`phase2` 是统一 DAG 的消去和缩聚总 wall；探针累加的是多个任务的 elapsed，不能解释为进程 CPU 时间。`backtransform` 只包括向量恢复；`normalize` 单独计入反排列和 M 归一化。读取阶段包括解析和稀疏矩阵构造。应用的结果检查/文本输出与进程启动关闭开销不应归入求解算子收益。

性能对照同时检查同树特征值等价、参考特征值误差及恢复向量残差。退出 0 和同树结果等价不代表截断参数满足精度要求。TK 的近零第一模态不适合直接使用相对特征值误差；应报告非零模态指标及第 200 阶误差。
