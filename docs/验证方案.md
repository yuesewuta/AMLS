# AMLS 验证方案（纯代数版）

> 版本：v0.2（2026-10-04）——术语代数化，与设计文档 v0.2 对齐
> 验收标准（用户确认）：频率相对误差 ≤ 2%。**系统内统一使用其代数等价形式：特征值相对误差 ≤ 4%**
> （f ∝ √λ ⇒ ε_f ≈ ε_λ/2）；参考解来源任意（按规模分级）

---

## 1. 验收指标定义

设参考特征对为 (λ_ref, x_ref)，AMLS 结果为 (θ, z)：

| 指标 | 定义 | 用途 |
|---|---|---|
| **特征值相对误差（主指标）** | ε_λ = \|θ − λ_ref\| / \|λ_ref\| | **验收：全部目标阶 ε_λ ≤ 4%** |
| 频率相对误差（等价口径） | ε_f = \|√θ − √λ_ref\| / √λ_ref ≈ ε_λ/2 | 仅对外报告/与文献口径对照时使用 |
| 残差范数 | r = ‖Kz − θMz‖₂ / (‖Kz‖₂ + \|θ\|·‖Mz‖₂) | 无参考解时的自洽性检查 |
| 特征向量夹角 | sin∠(z, x_ref)（M-内积下） | 诊断 |
| 耗时 / 峰值内存 | wall time、RSS | 与移位反演法对比（Phase 5） |

参考解分级：

| 算例规模 | 参考解方法 |
|---|---|
| n ≤ 5000 | LAPACK DSYGVD 全谱（金标准） |
| n > 5000 | Spectra `SymGEigsShiftSolver`（移位反演，Cholesky 模式）取低端 nev + 余量阶 |
| 闭式谱算例 | 解析公式 |

## 2. 测试算例集

### 2.1 闭式谱算例（正确性回归，单元级）

均为纯图论/离散算子算例，与任何物理来源无关：

| 算例 | K | M | 闭式谱 |
|---|---|---|---|
| 链式图 Laplacian（n 个顶点） | 三对角 [−1,2,−1] | I；另测三对角一致变体 | λ_j = 2−2cos(jπ/n)，j = 1..n−1 |
| 二维规则网格 Laplacian（5 点 stencil，nx×ny） | 块三对角 | I | λ_jk = 2−2cos(jπ/(nx+1)) + 2−2cos(kπ/(ny+1)) |

用途：M1 对 LAPACK 封装回归；M2/M3 对 AMLS 端到端回归；同时承载结构性质 P2/P13 的统计验证（边界列数、nnz(L) 渐近拟合）。

| 组 | 矩阵对 | 规模（约） | 用途 |

| HB | bcsstk01 / bcsstm01 | n=48 | 接口冒烟、单测 |

下载方式：`https://sparse.tamu.edu/MM/<Group>/<Name>.tar.gz`，脚本化（Phase 1 提供 `tools/fetch_matrices.sh`）。

### 3.3 参数扫描实验（`apps/amls_verify`，写入验证报告）

1. **η（thresholdFactor）扫描**：η ∈ {1.2, 1.5, 2.0, 3.0, 4.0}，记录 ε_λ 曲线、n_proj、耗时——验证 ρ-factor 理论预期（η≥2 后收益递减）；
2. **nLevels 扫描**：nLevels ∈ {2..6}，总保留谱分量预算近似恒定（参照 Gao et al. Table II/III 的做法），记录 Phase1/Phase2 耗时拐点；
3. **投影问题求解器对比**：DSYGVD（全谱）vs DSYGVX（区间）在不同 n_proj 下的耗时；
4. **AMLS vs 移位反演 Lanczos**（Phase 5）：nd12k/nd24k 上 nev ∈ {50, 100, 200, 500}，耗时与内存对比，预期 nev 越大 AMLS 优势越明显（TOMS 结论）。

## 4. 误差超标的处置预案

若某算例 ε_λ > 4%，按以下顺序排查（写入验证报告）：

1. 提高 η（截断误差主导？）；
2. 检查截断策略是否漏掉 ρ-factor 大的谱分量（TOMS §2.3 已指出纯 ρ 阈值的启发式局限）；
3. 检查局部谱问题求解精度（τ_sub 建议 1e-10，τ_proj 1e-5，Gao et al. 取值）；
4. 检查 K 半正定导致的零特征值污染（图 Laplacian 的常向量零谱）——必要时对 K 做小移位；
5. 仍不达标则引入后处理：对 AMLS 结果做 1~2 步块子空间迭代精化（Yi–Voss–Chen 方法，文献 #9，预留扩展点）。
