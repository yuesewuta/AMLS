# 环境与构建说明

> 版本：v0.1（2026-10-04）
> 平台：Windows + MSYS2（`D:\msys2`），主用 mingw64 环境

| 组件 | 版本 | 来源 |
|---|---|---|
| gcc / g++ / gfortran | 16.1.0 | `pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-gcc-fortran` |

## 2. 已安装的数值库（mingw64）

| 库 | 包名 | 说明 |
|---|---|---|
| OpenBLAS | `mingw-w64-x86_64-openblas` | 提供 BLAS + LAPACK（LP64 接口），头文件/库在 `D:\msys2\mingw64\{include,lib}` |
| Eigen3 | `mingw-w64-x86_64-eigen3` | 头文件在 `D:\msys2\mingw64\include\eigen3` |
| SuiteSparse | `mingw-w64-x86_64-suitesparse` | 含 CHOLMOD 等，v1 不链接、接口预留 |
| Catch2 | `mingw-w64-x86_64-catch` | v3（`catch2/catch_test_macros.hpp`，链接 `Catch2::Catch2WithMain`） |

安装命令（已全部执行）：

```bash
pacman -S --needed mingw-w64-x86_64-openblas mingw-w64-x86_64-eigen3 \
    mingw-w64-x86_64-suitesparse mingw-w64-x86_64-gcc-fortran mingw-w64-x86_64-catch
```

## 3. METIS + GKlib（工程内编译，已完成并验证）

源码位置：`third_party/metis`、`third_party/GKlib`（KarypisLab，master 分支快照）。

### 3.1 GKlib 构建（注意两个 MinGW 坑）

```bash
cmake -S third_party/GKlib -B third_party/GKlib/build -G Ninja \
      -DCMAKE_BUILD_TYPE=Release \
      -DHAVE_REGEX_H=OFF \        # 坑1：mingw64 有 regex.h 头文件但无实现，
                                  #       必须强制使用 GKlib 自带 gkregex
      -DCMAKE_C_STANDARD=99       # 坑2：gcc16 默认 C23，true/false/bool 成为
                                  #       关键字，与 gkregex.c 旧代码冲突
cmake --build third_party/GKlib/build --target GKlib
# 产出：third_party/GKlib/build/libGKlib.a
```

### 3.2 METIS 构建（需先生成 xinclude 头）

```bash
# METIS 的 Makefile config 步骤会拼出 build/xinclude/metis.h（前缀两个宏）
mkdir -p third_party/metis/build/xinclude
{ echo "#define IDXTYPEWIDTH 64";  echo "#define REALTYPEWIDTH 64";
  cat third_party/metis/include/metis.h; } > third_party/metis/build/xinclude/metis.h
cp third_party/metis/include/CMakeLists.txt third_party/metis/build/xinclude/

cmake -S third_party/metis -B third_party/metis/build -G Ninja \
      -DCMAKE_BUILD_TYPE=Release \
      -DGKLIB_PATH=<绝对路径>/third_party/GKlib \
      -DSHARED=OFF -DCMAKE_C_STANDARD=99
cmake --build third_party/metis/build
# 产出：third_party/metis/build/libmetis/libmetis.a
# 注：programs/（gpmetis 等命令行工具）链接失败可忽略，我们只用静态库
```

### 3.3 使用约定

- 头文件：**必须**包含 `third_party/metis/build/xinclude/metis.h`（含 64 位宏），而非 `include/metis.h`；
- ABI：`idx_t = int64_t`、`real_t = double`（已冒烟验证 `sizeof` = 8/8），C++ 侧 `Index = int64_t` 与之对齐；
- 链接顺序：`libmetis.a` 在前、`libGKlib.a` 在后，加 `-lm`；
- 冒烟测试（3×3 网格二分）已通过：`METIS_PartGraphRecursive` 返回 `METIS_OK`。
