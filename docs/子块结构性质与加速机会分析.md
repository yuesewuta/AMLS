# 分割后子块的结构性质与加速机会分析

> 版本：v1.1（2026-10-04）——术语代数化：本文与系统设计统一使用树模型术语（叶节点/分割节点/根节点），
> "谱分量"指局部特征向量，"截断阈值"指 λ_cut；(K, M) 仅为对称/对称正定稀疏矩阵对，不预设任何物理来源
> 地位：**架构级结论文档**——本文决定 Transformer（Phase 1）的全部实现策略
> 依据：Gao et al. 2008（TOMS）§2–§3、Bennighof & Lehoucq 2004、嵌套剖分理论（George 1973）；P1–P14 为可验证的性质命题

---

## 0. 结论先行

**"稠密化爆炸"确实会发生，但只发生在三种错误写法上；AMLS 的全部效率来自对 6 个结构性质的利用。** 按重要性排序的支柱：

1. **P3：投影后的 K̃ 是严格对角矩阵**——投影问题的"一半"免费；
2. **P5：结合顺序（Z-优先）**——同一个公式 `(M_ji − K_jiK_ii⁻¹)Z_i`，先算括号还是后算括号，复杂度差两个数量级；
3. **P1：叶节点块永不修改、保持原始稀疏**——叶节点的局部谱问题和局部因子分解都是稀疏问题；
4. **P2：耦合块的列稀疏（边界列）**——三角求解的右端数 = 边界索引数 ≪ 节点规模；
5. **P7：树祖先局部性**——每个节点只与 O(层数) 个祖先交互，总块操作量 ∝ 树边数而非节点数²；
6. **P13：嵌套剖分的填充上界**——全局层面保证"不会爆炸"的数学定理。

---

## 1. 记号

嵌套剖分（对 |K|+|M| 的邻接图递归二分）产生 separator tree。节点三角色：**叶节点**（不再二分）、**分割节点**（其索引集使子图分裂为不连通两部分）、**根节点**（无父的第一级分割节点）。对节点 i：`Ancestors(i)` = 到根路径上的节点集，`Descendants(i)` = 子树内节点集。nᵢ = 节点 i 的索引数，kᵢ = 截断后保留谱分量数（kᵢ ≪ nᵢ），p = Σkᵢ = 投影问题规模，ℓ = 剖分层数。

同余变换后：K̂ = L⁻¹KL⁻ᵀ 块对角；M̂ = L⁻¹ML⁻ᵀ 与 M 同块结构；S = diag(S₁,…,S_N) 为块对角的谱分量矩阵；投影对 (K̃, M̃) = (SᵀK̂S, SᵀM̂S)。

## 2. 性质清单与加速对策

### P1. 叶节点对角块 (K_ii, M_ii) 在消元中永不修改，保持原始稀疏性

> 来源：TOMS §2.2——"only those diagonal blocks corresponding to separators are modified. Diagonal blocks corresponding to the leaves are not altered."

- **含义**：叶节点的局部谱问题 (K_ii, M_ii) 是**原矩阵的子块**，稀疏模式与原图结构局部一致（每行 O(1)~O(10) 非零）。只有分割节点对角块被 Schur 更新填充变稠（K̂_ii、M̂_ii 稠密，但规模小）。
- **对策**：
  - 叶节点规模 ≤ ~2000：稠密化走 LAPACK（可控）；
  - 更大：保持稀疏，稀疏 Cholesky/LDLᵀ 分解 + 移位反演求部分谱（接口已预留）；
  - 叶内再排序（AMD/METIS-ND）进一步压填充——叶节点分解总代价 ≈ 一次带 ND 排序的全局稀疏分解的对应部分，不会更差。

### P2. 耦合块 K_ji、M_ji 的列稀疏：非零列 = 边界列

> 设 j ∈ Ancestors(i)：K_ji 的第 c 列非零 ⟺ 节点 i 的第 c 个索引与分割节点 j 在图中直接邻接——即"i 相对 j 的边界（boundary）"。

- **量级**：d 维网格类图中，规模为 nᵢ 的节点的单层边界索引数 ~ O(nᵢ^(1−1/d))。二维：O(√nᵢ)；三维：O(nᵢ^(2/3))。且**祖先层级越高，直接邻接的列越少**。
- **对策（两个数量级的节省来源）**：
  - 计算 K_jiK_ii⁻¹ 的作用时，三角求解右端数 = 边界列数 bᵢ ≪ nᵢ；
  - 数据结构：耦合块显式存 `(colMap: 局部列号→全局列号, denseCols)`，全零列物理上不存储；
  - M_ji 同理（M 的图通常与 K 一致或更窄，见 P14）。

### P3. K̃ = SᵀK̂S 是严格对角矩阵

> 来源：TOMS §3.3——"K̃ ≡ SᵀK̂S is diagonal"。

- **推导**：K̂ 块对角 + S 块对角 ⇒ K̃ 块对角；每块 S_iᵀK̂_iiS_i = diag(μ₁,…,μ_{kᵢ})（局部特征值）⇒ 整体对角。
- **含义**：投影问题的 K̃ **不需要任何计算**——它就是各节点被保留特征值排成的对角阵，存储 O(p)；投影问题的全部工作量集中在 M̃。
- **对策**：K̃ 用 `Vector` 存。

### P4. M̃ 的块非零结构 = M 的块结构，且所有对角块为对角阵

> 来源：TOMS §3.3——"M̃ typically has the same block nonzero structure as that of M. Furthermore, the diagonal blocks of M̃ are all diagonals."

- **含义**：M̃ 是 p×p 但**块稀疏**——M̃_ij ≠ 0 仅当节点 i、j 在树上有祖先-后代关系；对角块 S_iᵀM̂_iiS_i = I（见 P8）免费。
- **对策**：M̃ 按"树块表"存储；p 达数千时仍远小于 p² 的稠密存储；即使最终稠密化求解（P12），块结构仍决定**装配**阶段的计算量。

### P5. Z-优先的结合顺序：实现的性能分水岭 ★最关键★

> 来源：TOMS §3.1（Figure 2 伪代码 line 12）：M̄_ji = (M_ji − K_jiK_ii⁻¹)Z_i，j ∈ Ancestors(i)。

| 顺序 | 展开 | 中间量 | 复杂度（bᵢ=边界列数） | 判定 |
|---|---|---|---|---|
| ✗ 括号优先 | (M_ji − K_ji·**K_ii⁻¹**)·Z_i | K_jiK_ii⁻¹ 是 **n_j×nᵢ 稠密阵** | O(nᵢ³) 外加深 O(n_j·nᵢ²) 乘法 + 稠密存储 | **计算量爆炸** |
| ✓ Z-优先 | M_ji·Z_i − K_ji·(**K_ii⁻¹·Z_i**) | T = K_ii⁻¹Z_i 为 nᵢ×kᵢ | 稀疏分解一次 + kᵢ 列三角求解 + 两次稀疏×稠密乘（仅 bᵢ 个非零列参与，P2） | 正确路线 |

- **kᵢ 把列维度从 nᵢ 压到 kᵢ**：后续所有块运算都在高瘦块 M̄_ji（n_j×kᵢ）上进行（TOMS："M̄_ji has far fewer columns than M_ji"）。
- **对策（架构级）**：`Transformer` 中**禁止显式求逆 API**；块消元一律以 `solveWithFactor(B)` 算子形式存在；结合顺序列入代码评审硬性检查项。

### P6. K 的更新是单边的，M 的更新是双边的

> 来源：TOMS §3.1——L_ei⁻¹K 消去 i 块列下方元素后，右乘 L_ei⁻ᵀ 不再修改右下尾随块；而 L_ei⁻¹M 不产生零块，M 必须左右都乘。

- **对策**：K 侧只需维护分割节点对角块的 Schur 累加（右端仅 bᵢ 列）；M 侧需要完整双边更新——这正是 M̂ 不能显式存储、必须交错投影的原因（与 P5 联动）。

### P7. 树祖先局部性：块操作总量 ∝ 树边数

> 来源：TOMS §3.1（Figure 3/5/6 的阴影块示意）。

- **性质**：消去节点 i 只触碰 {i} ∪ Ancestors(i) 相关块；分割节点额外触碰后代方向已投影的高瘦块（P5）。
- **量级**：每节点交互对象 O(ℓ) 个；总块操作数 O(N·ℓ)（N = 节点数），而非 O(N²)。
- **对策**：`SeparatorTree` 的 ancestors/descendants/postOrder 是 Transformer 的唯一遍历依据；该性质也是树任务级并行的合法性基础（不同子树的消元相互独立）。

### P8. 局部谱分量的 M̂-正交性：投影矩阵对角块免费

- Z_i 取 (K̂_ii, M̂_ii) 的 M̂-归一特征向量 ⇒ S_iᵀM̂_iiS_i = I_{kᵢ}，S_iᵀK̂_iiS_i = diag(μ)。
- **含义**：AMLS **不需要构造或维护全局正交基**（TOMS 引言列出的两大效率来源之一）。
- **对策**：装配 M̃ 时对角块直接填单位阵，零计算量；M̃ 天然对称正定。

### P9. ρ-factor 谱衰减：局部谱问题只需求部分谱

> 来源：TOMS §2.3（Yang et al. 2005 的分析）：全局特征向量在局部谱基下的展开系数 ∝ ρ_λ(ω) = |λ/(ω−λ)|。

- **含义**：远离目标谱区间的局部谱分量贡献代数衰减——截断阈值 λ_cut = η·λ_max（η≈2）以外的分量可安全丢弃。
- **对策**：局部谱求解**按区间/前 k 阶取**（LAPACK `DSYGVX` 区间模式，或移位反演取低端 kᵢ 个），而非全谱；η 是唯一精度旋钮（η 扫描实验见《验证方案》§3.3）。

### P10. 全程对称正定 ⇒ 无 pivot 分解

- K 正定 ⇒ 主子块 K_ii 正定；Schur 补 K̂_jj 正定（SPD 的 Schur 补仍 SPD）；M、M̂_ii、M̃ 均 SPD。
- **对策**：全链路 Cholesky / 无 pivot LDLᵀ——更快、更省、无 pivoting 对块结构的破坏（TOMS §2.3 警告过 K 不定时缺全局主元的风险，本系统界定的输入范围恰好避开）；实现中检测负主元即报错，作为范围外输入的保护。

### P11. L 的可重构性（半隐式表示）

> 来源：TOMS §3.2。叶节点块 L_ji = K_jiK_ii⁻¹ 不显式形成，需要时用 K_ii 的因子 + K_ji 重算（右端仅 bᵢ 列）。

- 内存省约 50%、时间代价 <15%（TOMS 实测）；v1.0 显式存储分割节点块 L_ji 保证正确性，v1.1 打开半隐式（`AmlsOptions::semiImplicitL`）。

### P12. 投影问题规模可控且存在求解策略切换点

- p 由截断阈值与层数控制；TOMS 实测 **p ≤ 5000 时稠密 DSYGVD 显著快于移位反演**；更大时切换预留接口。
- 对策：`AmlsOptions::denseProjectedMax = 5000` 自动切换。

### P13. 嵌套剖分的填充上界（全局"不爆炸"的数学保证）

> 来源：George 1973 及后续 ND 理论。

- 对 d 维网格类图：ND 排序下稀疏 Cholesky 填充 nnz(L) = O(n log n)（二维）/ O(n^(4/3))（三维），分解 flops = O(n^(3/2))（二维）/ O(n²)（三维）；顶层分割节点尺寸 O(n^(1/2)) / O(n^(2/3))。
- **含义**：Phase 1 总代价 ≈ 一次 ND 排序的全局稀疏分解 + 一组小稠密谱问题——这是 AMLS 在大 nev 时数倍快于移位反演 Lanczos 的原因（后者同样付一次移位分解，还要再付每轮迭代的三角回代）。

### P14. M 的非零模式 ⊆ K 的非零模式（常见情形）

- 离散问题中 M 常与 K 同图或更窄（如对角 M）。
- **对策**：耦合块、边界列映射可对 K、M 共用一套索引结构（实现时做 `shared_sparsity` 检测，不满足时各自维护）。

## 3. 量化对照：贸然稠密化 vs 利用结构

以二维网格图算例 n = 10⁶（1000×1000，5 层剖分 → 32 个叶节点）估算：

| 量 | 贸然稠密化 | 利用结构后 | 倍率 |
|---|---|---|---|
| 单叶节点存储 | 31 250² ≈ 7.3 GB（double） | 稀疏 nnz ≈ 5·31250 ≈ 1.3 MB + 因子 | ~4 个数量级 |
| 耦合块三角求解右端数 | nᵢ = 31 250 | bᵢ ≈ O(√nᵢ) ≈ 数百 | ~2 个数量级 |
| M̄_ji 块列数 | nᵢ | kᵢ（截断后，典型几十） | ~3 个数量级 |
| 投影问题 K̃ | p² 稠密 | **对角**，O(p) | p 倍 |
| 全局填充 | 无界（稠密化） | nnz(L) = O(n log n)（P13） | 定理保证 |

## 4. 对架构的反哺（设计文档的硬约束）

Phase 1 编码必须落地的四条：

1. **块算子接口**：`ISparseDirectSolver::solveWithFactor(B)` 与耦合块 `applyRight(Z)` 为唯一合法操作形态；**不得存在**显式矩阵求逆或显式 `K_ji × K_ii⁻¹`（P2/P5/P11）；
2. **耦合块边界列数据结构**：`CouplingBlock { colMap; denseCols; }`（P2/P14）；
3. **局部谱求解接口签名为区间/前 k 阶**，不允许"全谱后截断"（P9）；
4. **K̃ 对角存储、M̃ 树块表存储**，装配按 P3/P4/P8 跳过免费部分。
