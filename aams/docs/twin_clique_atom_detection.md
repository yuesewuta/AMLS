# twin-clique 代数原子检测（置换不变，替代布局式 dp=3 硬编码）

日期：2026-10-19。实现：`aams/src/ams/tree_builder.cpp` `detectTwinAtoms`（auto 路径默认启用，
`AAMS_NO_TWIN=1` 关闭走旧回退）。动机与 dp 泛化背景见
`docs/abaqus_ams/AMS块原子等于节点DOF数验证.md`。

## 动机

AMS 的消元块原子 = 网格节点 DOF 数 dp。旧自动检测 `detectGroupedLayout(A, 3)` 依赖
**布局先验**（按 dof 编号 3t..3t+2 分组验证），一旦矩阵经历置换（外部工具、导出顺序
差异）即失效。代数上正确的定义是 **twin-clique**：一类 C 中所有成员共享外部邻域
N(u)\C ≈ N(v)\C——完全置换不变。

难点：Abaqus 导出的 stf/mtx **系统性丢掉微小耦合项**。cant_20 有 1495/8820 节点
缺失组内 (0,1)/(0,2) 边、7 组组内边全丢；cant_31 约 80% 节点至少缺一条跨节点项。
因此不能做精确邻域相等，必须容忍带噪声的"近孪生"。

## 容差标定（delta_probe 实测，cant_31）

| 量 | 实测分布 |
|---|---|
| 同三元组 dof 对 |N(u)ΔN(v)| | ≤ 16（99.8% ≤ 10） |
| 跨三元组边 |N(u)ΔN(v)| | ≥ 14 |
| 重叠区 14–16 | ~11 真对 vs ~200 假跨边 |

⇒ 双门槛：`limMerge=13`（并查集合并阶段，排除全部假跨边）、
`limVerify=16`（分量校验/挂靠/聚类——合并后分量已纯，可放宽）。

## 四阶段流水线

1. **阶段 0 精确孪生桶**：Zobrist XOR 邻域指纹分桶，捕获组内边全丢但成员
   非邻接的组（边测试永远够不到）；指纹只提名，`sameAdj` 精确复核。
2. **阶段 1 近孪生边 + 并查集**：对称差早停 ≤limMerge + 交集下限
   `inter ≥ min(deg)−(cmax−1)`；分量 `verifyClass`（2 ≤ |C| ≤ 6，外部对称差
   ≤ limVerify）不过则拆散为游离 dof。
3. **阶段 2 游离挂靠**：真类单例（组内两条边都丢、与类成员互不相连、外部
   指纹也因非对称丢边不同）→ 候选类三来源（距离1邻类 / **距离2**：邻居 e 的
   邻居已入类——真类成员与单例共享整个外部邻域，只要任一条 a–e 边幸存即被
   提名 / 指纹桶），按外部对称差 |E_u Δ E_C0| 升序尝试。cant_31 挂靠 1472
   成功，其中 242 仅靠距离 2 找回。
4. **阶段 3 单例聚类**：剩余单例两两 delta ≤ limVerify 聚类。

## 统一 classOf 流水线

`extractClassGraph`（按 classOf 收缩两端点）替代 extractNodeGraph；permND 经
成员 CSR（mStart/mList）+ nodeOff 前缀和展开；An 三元组经 classOf；METIS vwgt
仅在类宽不均匀时构建（均匀时传 nullptr → 与旧路径逐位一致，已验证）。

## 验证（实测，16 线程，--fmin 0 --fmax 120 --cutoff1 5 --reduced distill）

### cant_31（n=95232）

| 路径 | 检测 | residual | TOTAL |
|---|---|---|---|
| legacy dp=3 | nv=31744 | 0.79703/0.75638 | 25.32s |
| twin（修复 245 断三组后） | 3:31743, 单例=1, 覆盖 99.999% | 0.78380/0.75501 | 25.63s |
| twin 首版（245 对断裂） | 单例=243 | 0.77982/0.71477 | 29.5s |

频率 twin vs legacy 前 20 阶差 ≤ 0.35%；REDUCTION 反而更快（14.48 vs 14.67s），
开销集中在检测+vwgt 的 METIS_ORDERING_BUILD_TREE（1.68 vs 1.33s）。

### cant_20（n=26460）

| 路径 | 检测 | TOTAL |
|---|---|---|
| legacy dp=3 | nv=8820 | 2.34s |
| twin | 2:1 3:8815 4:1 6:1, 单例=1, nv=8820 | 2.39s |

前 10 阶频率差 ≤ 0.5%（模式 8 最差，属 METIS 树形噪声量级；其余 ≤ 0.1%）。

### 置换实验（随机 PAPᵀ，seed=20261019）

| 路径 | 结果 |
|---|---|
| twin @ PAPᵀ | 类宽 2:1 3:8816 4:1 6:1, 单例=0, 覆盖 100%（连原序遗留的那 1 个单例也挂上） |
| legacy @ PAPᵀ | `detectGroupedLayout` 失效 → 回退 dp=1, nv=26460（旧检测必败，符合预期） |
| 频率 | twin@PAPᵀ vs twin@A 前 12 阶差 ≤ 0.2%（同为 METIS 噪声量级） |

原子结构逐类一致 ⇒ 检测置换不变得证。

## 已知残留

- 每个算例遗留 1 个无法归类的单例（外部差超限/距离 2 也找不到），对结果影响可忽略；
  cant_31 该单例使 nv 比 legacy 多 1（31745 vs 31744）。
- 类宽 4/6 的类是相邻原子在容差内的意外合并（外部对称差 ≤16），频率对比未见劣化；
  如需更严可回退 limVerify。
- 混合类宽走 vwgt 路径时 METIS 树与均匀 dp=3 略有差异（+1~2% 总时长）。
